Server API Console

All endpoints of the Server module. Authentication: HTTP Basic.

no credentials
RestApi — /rest
GET /rest/cookies Cookie list (static JSON)
GET /rest/posts Posts fetched via WebClient
GET /rest/passphrase Passphrase fetched via WebClient
GET /rest/risk Throws BasicException → exercises ExnHandler
POST /rest/file/{content} Saves content to a file
BankingApi — accounts, cards, countries
GET /accounts Account list
POST /accounts Creates an account
GET /cards Card list
POST /countries Creates a country
OrderApi — orders
POST /orders Creates an order
PUT /orders/{id} Full replace, send the version you read or get 409
GET /orders All orders
GET /orders Blank fields are skipped the rest are ANDed.
AuditApi — audits
GET /audits — newest first. Timestamps are ISO-8601 with an offset.
